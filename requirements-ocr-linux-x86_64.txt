# Linux x86_64 production OCR baseline.
# Keep this on the PaddleOCR 3.x line so production can use HPI/OpenVINO/TensorRT
# optimizations. Exact patch versions should be promoted after OCR benchmark runs.
# Held below 3.3.0: paddlepaddle 3.3.x crashes on every predict call in the
# PIR -> oneDNN attribute conversion (Paddle#77340, still open), so oneDNN has to
# be switched off there — which costs ~6x on CPU OCR (10.9s vs 1.8s per page,
# byte-identical text). Lift this pin once #77340 ships a fix — and move the
# version gate in _paddle_supports_onednn()
# (services/docreader/mantisfetch_docreader/paddle_ocr_worker.py)
# in the same change, or oneDNN stays off on the newer version and the ~6x is lost.
paddlepaddle>=3.2.0,<3.3.0
# Floor at 3.7.0, the version production has run and verified since 2026-07-26.
# Without it a `refresh_constraints.sh --upgrade` traded it down to 3.4.1 (with
# paddlex 3.4.3) to fit a newer numpy (2.4.6): the resolver ranks the direct
# numpy requirement ahead of this one, and CI installs no OCR to notice (#338).
paddleocr>=3.7.0,<4.0.0
